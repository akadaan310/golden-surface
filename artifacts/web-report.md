# GOLDEN MOTION web laboratory evidence

Implemented in `apps/web/`. Local-only Next.js 15.5.27, React 18.3.1, TypeScript, Three.js 0.171 and React Three Fiber 8.18. The Pages Router preserves the required React 18 renderer; an initial App Router browser failure (`ReactCurrentOwner`) was reproduced and resolved by removing the incompatible React 19 runtime boundary.

## Delivered behavior

- Responsive dark/gold research interface with spatial, dedicated RF and evidence workspaces, virtual smartphone, articulated hand proxy, visible proxy zone, animated acoustic/magnetic fields, measurement traces, quality, uncertainty and SDK gesture timeline. Demand rendering schedules no animation in standby. Automatic low power mode detects software renderers, mobile-width screens and reduced-motion preferences; it uses DPR 1, no shadows/antialiasing and a 20 Hz animation scheduling clock, with balanced scheduling at 30 Hz and field updates limited to 30 Hz. A quality override exposes the visual-cost tradeoff. Renderer-frame counters distinguish actual scene renders from browser RAF cadence.
- Actual deterministic 48 kHz chirp generation, delayed echoes, noise, multipath and timing drift; independent matched-filter detection and scalar range estimation. No-hand removes the echo only in the forward model. Detection/confidence use received correlation peaks and observed trailing-window noise, not hand-presence truth. Competing observed echoes reduce confidence and enlarge the uncertainty heuristic.
- Synthetic dipole-field samples and scalar inverse, explicit negative controls, dropout, measured range-band editing, synthetic spatial-zone editing, reference bias correction against a known simulator reference, bounded replay and observation export.
- Intentional semantic actions subscribe to shared `@golden-motion/isi` events. Sensor scrolling uses inferred event deltas. Translation/rotation/avatar modes explicitly switch to the synthetic metric proxy adapter; they do not turn scalar sensor observations into 3D positions.
- Opt-in browser MediaPipe image-plane hand landmarks. New decoded frames preserve their browser acquisition epoch captured before inference, with processing completion stored separately; this does not claim a hardware exposure timestamp. Host ticks call SDK dropout detection, and independent frame identity prevents a frozen processed observation from re-entering after dropout. No-hand frames immediately withhold position and set confidence to zero. All WASM/model assets are served locally. Explicit camera stop, five-minute bound and automatic release on visibility loss, page exit, modality change and unmount. No raw media is uploaded, recorded or exported. Local asset origin, hashes and Apache-2.0 license are in `public/vision/`.
- Shared `@golden-motion/rf` channel simulation and estimation, with configurable TX/RX/reflector xyz, frequency, bandwidth, subcarriers, SNR, packet loss, CFO/SFO, phase noise, clock drift and static multipath. Includes a no-reflector control, raw CSI amplitude/phase, the shared estimator's common-phase-cancelled Doppler spectrum, coarse RSSI, quality and unsigned bistatic ambiguity.
- CSI relative scrolling is an explicit synthetic trigger policy with independently armed intent and a user-selected direction, activated only by SDK hover observations. It does not infer signed hand motion. RSSI has no directional scrolling gesture.
- Authenticated loopback RelayClient with capped reconnect and sequence validation. Tokens stay in memory and are erased on disconnect. Preview driving is separately opt-in and requires armed acquisition, adequate quality, supported semantics and epoch clocks aligned within one second. Stale/unsupported/low-confidence events release preview state; invalid events and connection errors also release it. Monitoring preserves source/frame even when actions are withheld. Synthetic reference panels retain explicit labels during relay preview.
- Evidence workspace fetches executed Python acoustic/RF/classifier fixtures, including false activations and held-out generated-session results, and links the underlying JSON.

## Limits

Synthetic evidence remains synthetic. Acoustic range is scalar, magnetic range assumes an ideal calibrated dipole, and CSI path rate is unsigned and cannot localize a reflector. The 3D proxy and geometry are configured reference truth unless a supported authenticated metric event explicitly supplies coordinates. Browser frame acquisition epoch is captured when a new decoded frame is observed before inference, with hardware exposure time unavailable; processing completion is retained separately. Camera z=0 is a schema placeholder and is never measured depth. Camera confidence uses an uncalibrated handedness-classifier score, not a demonstrated probability of landmark accuracy.

Uncertainty and confidence are explicitly uncalibrated quality heuristics; simulated reference capture is not physical calibration. RF trigger policy does not establish hand identity or intentional gesture classification. Real camera hand accuracy, Galaxy A16 acoustic/magnetic feasibility and access to live Wi-Fi CSI remain unverified. Camera QA used Chromium's synthetic test device and verifies local inference lifecycle, not physical hand tracking. Replay is bounded to 180 in-memory observations, with stored generated acoustic/magnetic traces; raw camera frames and raw physical RF packets are never retained.

No website publication, credentials, external hosting or physical sensor accuracy claims were made.
